# HTTP 状态和错误契约

## 响应结构

除文件下载和 Actuator 外, 业务接口统一使用:

```json
{
  "code": 40002,
  "message": "请求格式或参数类型不正确",
  "data": null
}
```

- `code = 0` 表示成功.
- HTTP 状态表达协议结果, 业务 `code` 用于客户端稳定识别具体错误.
- HTTP 500 不返回异常类名、SQL、路径或堆栈, 完整异常只记录在服务端日志.

## 状态码

| HTTP 状态 | 使用场景 |
| --- | --- |
| `200` | 查询、更新、状态动作和带响应体的软删除成功. |
| `201` | 创建组织、用户、围栏、停车点、任务、规则或附件, 同时返回 `Location`. |
| `202` | 雅迪 Mock 事件或异步报表已接收, 但尚未完成处理. |
| `400` | Bean Validation、JSON、参数类型、必填参数或业务输入不合法. |
| `401` | 未登录或登录凭据错误. |
| `403` | 角色、数据范围或 CSRF 校验失败. |
| `404` | 资源或接口不存在. |
| `405` | HTTP 方法不支持, 响应包含 `Allow` 头. |
| `406` | 无法生成客户端要求的响应媒体类型. |
| `409` | 唯一资源重复、并发版本或业务状态冲突. |
| `413` | 上传文件超过 8 MB. |
| `415` | 请求媒体类型不支持. |
| `500` | 未预期服务端异常. |

## 上传限制

Spring MVC 和业务校验统一允许单张作业凭证最大 8 MB, 整个 multipart 请求最大 10 MB. 容器层超限由统一异常处理器转换为 HTTP 413, 业务层继续校验实际文件大小、媒体类型和图片内容.
