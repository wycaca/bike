# App 设计

用户端 App 暂缓开发. 前期只做管理端和运维端能力, 用户端保留接口边界和 WebView 壳方案.

## 前期目标

优先实现运维端 H5:

- 运维员登录.
- 工单列表.
- 工单详情.
- 扫码识别车辆.
- 换电确认.
- 维修确认.
- 调度确认.
- 拍照上传.
- 当前位置上报.

用户端只做简单设计, 不进入首期开发.

## 用户端预留能力

后续用户端使用 Android WebView 套 H5:

- 找车地图.
- 扫码开锁.
- 骑行中状态.
- 还车.
- 支付.
- 行程记录.
- 客服和报障.

原生壳只保留必要能力:

- 定位.
- 扫码.
- WebView 安全配置.
- JSBridge.
- 支付唤起.
- 推送.

## 技术建议

- H5: Vue 3 + Vant.
- Android: Kotlin 或 Java 原生 WebView 壳.
- 地图: 高德地图.
- 登录态: 后端无状态, App Token 状态保存到 Redis.

## 暂缓原因

- 初创阶段先验证车辆运营, 工单处理, 轨迹和管理后台.
- 用户端涉及支付, 客服, 优惠, 月卡, 风控, 投诉等复杂业务, 过早开发会拉高成本.
- 运维端能先支撑线下运营, 对早期试点价值更直接.
