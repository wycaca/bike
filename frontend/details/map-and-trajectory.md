# 地图和轨迹交互

## 当前实现

- 地图查询当前城市视野, 支持在线状态和生命周期筛选.
- 查询条件变化使用短延迟合并, 新请求取消旧请求, 默认每 15 秒刷新.
- 地图点可以打开车辆详情抽屉, 异常车辆在侧栏集中展示.
- 地图只在城市切换时重置中心和缩放级别, 用户拖动或缩放后只刷新当前视野数据.
- 轨迹页支持时间范围查询, 轨迹摘要, 播放, 暂停, 进度拖动和速度调整.
- 轨迹里程使用相邻点球面距离估算, 只用于管理端摘要, 不作为计费依据.

地图和轨迹接口当前统一请求 GCJ-02, 后端从 WGS84 转换后返回. 配置本地高德 Web Key 时, 车辆分布和历史轨迹使用高德 JS API 2.0 展示; 未配置或 SDK 加载失败时保留坐标预览, 避免页面空白.

当前 Mock 数据量很小, 高德模式使用普通 Marker. 真实视野内点位达到性能瓶颈时, 根据浏览器性能测试改用高德海量点能力.

## 地图数据

- 地图使用高德地图 JS API 2.0.
- 前端使用 GCJ-02 展示坐标.
- 后端保留 WGS84 原始坐标.
- 地图请求只覆盖当前视野.
- 低缩放级别展示后端聚合点.
- 高缩放级别展示车辆点.

前端不实现 WGS84 到 GCJ-02 的近似转换, 地图展示坐标统一由后端转换.

## 请求策略

- 地图首次加载后请求当前视野.
- `moveend` 和 `zoomend` 后重新请求.
- 连续操作使用短延迟合并请求.
- 新请求发出时取消同类旧请求.
- 默认每 15 秒刷新当前视野.
- 页面不可见时暂停轮询.

暂不使用 WebSocket. 当真实业务要求小于 5 秒的可见延迟, 并且轮询成本已被监控证明不合适时再增加推送通道.

## 点位渲染

- 聚合在后端完成, 前端不接收全城车辆后再聚合.
- 当前小规模数据使用普通 Marker, 实际视野点位达到性能瓶颈时再切换高德海量点能力.
- 点位颜色区分正常, 低电量, 故障和离线.
- 选中车辆有唯一高亮状态.
- 筛选和图例使用相同颜色和状态定义.

## 轨迹回放

- 轨迹按时间升序绘制.
- 显示开始时间, 结束时间, 点数和坐标系.
- 支持播放, 暂停, 拖动进度和调整速度.
- 拖动或播放进度时显示对应轨迹点的时间, 速度, 电量和锁状态.
- 接口返回截断标志时必须提示用户缩小时间范围.
- 切换车辆或时间范围时清理旧折线和定时器.

轨迹接口单次最多 31 天和 10000 个点. 前端不绕过限制自动并发扫描更长历史.

## 高德密钥

- 本地 Web Key 只放在被 Git 忽略的 `frontend/.env.local`, 文档和代码不得记录实际值.
- 根目录 `.env.local` 中的 `AMAP_WEB_SERVICE_KEY` 只用于本地生成道路级 Mock 轨迹, 不得提供给浏览器或与 Web JS Key 混用.
- 生成的 Mock JSON 只保存路线结果和来源标识, 不保存任何 Key.
- Web Key 会出现在浏览器加载地址和本地构建产物中, 不得把本地镜像发布到公共仓库.
- 2021-12-02 之后创建的 Key 需要配套安全密钥. `securityJsCode` 不得进入前端构建产物.
- 生产环境使用 Nginx `_AMapService` 安全代理, 并为 Key 配置域名白名单和环境隔离.
